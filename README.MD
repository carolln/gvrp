Authors: Carolina Nunes de Carvalho, Arthur José Arruda Skeete, Ian Fernandes França

Implementation of heuristics and (futurely) meta-heuristics that refer to the Green Vehicle Routing Problem (GVRP)

compile the file with 

```bash
g++ mcws.cpp -o mcws
```

execute the file with
```bash
./mcws < instances/put_instance_name_here.txt
```
